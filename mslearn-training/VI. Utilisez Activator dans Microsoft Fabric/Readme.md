Fabric Activateor est un moteur de détection d’événements qui déclenche automatiquement des actions lorsque des modèles ou des conditions spécifiques sont détectés dans des sources de données.

## Objectifs d’apprentissage

- À la fin de ce module, vous serez en mesure de :

- Définir des objets de données et des propriétés dans Activateor
- Créer des règles qui évaluent les conditions dans vos données
- Configurer des actions qui s’exécutent lorsque des conditions de règle sont remplies
## Prérequis

Avant de commencer ce module, vous devez être familiarisé avec l’interface Microsoft Fabric et les concepts de base.
