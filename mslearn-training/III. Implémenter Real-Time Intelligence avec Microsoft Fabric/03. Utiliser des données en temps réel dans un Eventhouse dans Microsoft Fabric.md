# Utiliser des données en temps réel dans un Eventhouse dans Microsoft Fabric

*1 h 7 min*
- Module *(0 sur 7 unités terminées)*
Un eventhouse dans Microsoft Fabric est un conteneur qui héberge une ou plusieurs bases de données KQL pour stocker et analyser des données en temps réel.
