# Utilisez Activator dans Microsoft Fabric

*1 h 1 min*
- Module *(0 sur 7 unités terminées)*
Fabric Activateor est un moteur de détection d’événements qui déclenche automatiquement des actions lorsque des modèles ou des conditions spécifiques sont détectés dans des sources de données.

## Présentation

*4 min*
- Configurer l’activateur pour vos données *(7 min)*
- Créer des règles dans activateur *(6 min)*
- Configurer des actions dans Activateor *(3 min)*
- Exercice : utiliser Activator dans Fabric *(30 min)*
