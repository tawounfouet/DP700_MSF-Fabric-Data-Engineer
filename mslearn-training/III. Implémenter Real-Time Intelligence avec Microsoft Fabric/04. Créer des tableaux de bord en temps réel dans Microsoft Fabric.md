# Créer des tableaux de bord en temps réel dans Microsoft Fabric

*1 h 13 min*
- Module *(0 sur 7 unités terminées)*
Real-Time Tableau de bord est une fonctionnalité de Microsoft Fabric que vous pouvez utiliser pour créer des visualisations de données interactives.
