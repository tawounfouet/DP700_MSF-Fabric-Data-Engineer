# Sécuriser un entrepôt de données Microsoft Fabric

*1 h 11 min*
- Module *(8 Unités)*
Débutant
Analyste de données
Ingénieur Data
Microsoft Fabric
Un entrepôt de données dans Microsoft Fabric est une plateforme complète pour les données et l’analytique, avec des fonctionnalités avancées de traitement de requêtes et des fonctionnalités T-SQL transactionnelles exhaustives pour faciliter la gestion et l’analyse des données.

## Objectifs d’apprentissage

Dans ce module, vous allez :

- Découvrez les concepts de sécurisation d’un entrepôt de données dans Microsoft Fabric
- Découvrez comment implémenter le masquage dynamique des données pour masquer les informations sensibles
- Découvrez comment configurer la sécurité au niveau des lignes pour fournir un contrôle granulaire
- Découvrez comment implémenter la sécurité au niveau des colonnes pour protéger les données sensibles
- Découvrez comment configurer des autorisations granulaires à l’aide de T-SQL
## Prérequis

Avant de commencer ce module, vous devez vous familiariser avec l’interface de Microsoft Fabric et les concepts de base.
