Découvrez comment Microsoft Fabric peut répondre aux besoins d'analytique de votre entreprise sur une seule plateforme. Découvrez Microsoft Fabric, comment cela fonctionne et identifiez comment vous pouvez l’utiliser pour vos besoins d’analyse.

## Objectifs d’apprentissage

Dans ce module, vous allez apprendre à :

- Identifiez les fonctionnalités de Microsoft Fabric
- Implémentez Microsoft Fabric pour répondre aux besoins d'analytique de votre entreprise
- Décrivez comment Fabric prend en charge les fonctionnalités d’IA via Copilot, les agents de données et Fabric IQ
## Prérequis

Vous devez être familiarisé avec les concepts et la terminologie de l’analytique des données et de l’ingénierie.
