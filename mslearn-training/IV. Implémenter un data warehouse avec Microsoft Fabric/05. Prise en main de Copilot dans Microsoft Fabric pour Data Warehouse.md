# Prise en main de Copilot dans Microsoft Fabric pour Data Warehouse

*46 min*
- Module *(8 Unités)*
Intermédiaire
Analyste de données
Ingénieur Data
Microsoft Fabric
Accélérez l’analytique de l’entrepôt avec Copilot dans Fabric : utilisez la conversation IA, les achèvements inline et les actions rapides pour générer, affiner, expliquer et corriger T-SQL tout en appliquant des invites recommandées.

## Objectifs d’apprentissage

Dans ce module, vous allez apprendre à :

- Appliquez Copilot dans les expériences Fabric Data Warehouse pour accélérer l’interrogation, la création et la résolution des problèmes
- Générez, affinez, expliquez et corrigez T-SQL à l’aide d’une conversation, de saisie semi-automatique du code et d’actions rapides
- Incorporez des pratiques efficaces d’invite, d’affectation de noms et de conception de schémas qui améliorent la précision de Copilot
- Utilisez les fonctionnalités de Copilot de manière responsable pour améliorer la productivité tout en conservant la qualité et la gouvernance des données
## Prérequis

Vous devez être familiarisé avec les concepts et la terminologie de l’analytique des données et de l’ingénierie.
