# Commencez avec les entrepôts de données dans Microsoft Fabric

*1 h 16 min*
- Module *(9 Unités)*
Débutant
Analyste de données
Ingénieur Data
Microsoft Fabric
Découvrez ce qu’est un data warehouse Fabric, pourquoi il fournit des fonctionnalités transactionnelles T-SQL complètes et comment créer, interroger et transformer des données pour l’analytique.

## Objectifs d’apprentissage

Dans ce module, vous allez apprendre à :

- Décrire les concepts d'entrepôt de données et les notions fondamentales de la modélisation dimensionnelle

- Créez des tables, chargez des données et comprenez les méthodes d’ingestion dans un entrepôt Fabric

- Interrogez et transformez des données à l’aide de T-SQL et de l'éditeur de requêtes visuel

- Données de l’entrepôt de données modélisées pour la création de rapports et la consommation en aval

- Sécurisez et surveillez une data warehouse

## Prérequis

Vous devez être familiarisé avec l’interface Microsoft Fabric, les concepts de base de données relationnelle, les notions de base de données SQL et les concepts de modélisation dimensionnels de base tels que les tables de faits et de dimension.
