Microsoft Fabric
Un entrepôt de données dans Microsoft Fabric est une plateforme complète pour les données et l’analytique, avec des fonctionnalités avancées de traitement de requêtes et des fonctionnalités T-SQL transactionnelles exhaustives pour faciliter la gestion et l’analyse des données.

## Objectifs d’apprentissage

Dans ce module, vous allez :

- Découvrir différentes stratégies pour charger des données dans un entrepôt de données dans Microsoft Fabric
- Apprendre à créer un pipeline de données pour charger un entrepôt dans Microsoft Fabric
- Apprendre à charger des données dans un entrepôt à l’aide de T-SQL
- Apprendre à charger et à transformer des données avec Dataflow (Gen2)
## Prérequis

Avant de commencer ce module, vous devez être familiarisé avec les principes de base d’un entrepôt de données.
