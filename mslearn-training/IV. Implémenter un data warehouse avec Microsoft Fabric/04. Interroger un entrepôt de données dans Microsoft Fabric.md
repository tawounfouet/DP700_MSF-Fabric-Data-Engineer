# Interroger un entrepôt de données dans Microsoft Fabric

*1 h 7 min*
- Module *(8 Unités)*
Débutant
Analyste de données
Ingénieur Data
Microsoft Fabric
Dans ce module, vous allez apprendre à interroger un entrepôt de données dans Microsoft Fabric à l'aide des éditeurs de requêtes sql et visuels intégrés et des outils clients externes comme SQL Server Management Studio.

## Objectifs d’apprentissage

Dans ce module, vous allez :

- Utilisez l’éditeur de requête SQL pour écrire et exécuter des requêtes T-SQL sur un entrepôt de données
- Générez des requêtes à l’aide de l’éditeur de requête visuelle sans code
- Connectez-vous à un entrepôt de données à partir de SQL Server Management Studio à l’aide de l’authentification Microsoft Entra ID
## Prérequis

Avant de commencer ce module, vous devez être familiarisé avec les principes de base des entrepôts de données.
