# Utiliser des tables Delta Lake dans Microsoft Fabric

*1 h 8 min restant*
- Module *(0 sur 9 unités terminées)*
Les tables d’une Microsoft Fabric lakehouse sont basées sur le format de stockage Delta Lake couramment utilisé dans Apache Spark. En utilisant les fonctionnalités améliorées des tables delta, vous pouvez créer des solutions d’analytique avancées.
