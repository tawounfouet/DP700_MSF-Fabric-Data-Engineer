Microsoft Fabric est une plateforme SaaS (software as a service) pour l’analytique des données. Découvrez comment gérer votre environnement via l’intégration continue/le déploiement continu (CI/CD), la surveillance et la sécurité.

## Prérequis

Avant de commencer ce parcours d’apprentissage, vous devez avoir une expérience avec Microsoft Fabric ou Power BI. Vous devez également avoir une compréhension de base de l’engineering données et des concepts de gestion.
