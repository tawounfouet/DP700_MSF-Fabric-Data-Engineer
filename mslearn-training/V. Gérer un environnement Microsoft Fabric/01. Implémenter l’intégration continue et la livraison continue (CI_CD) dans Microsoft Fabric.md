# Implémenter l’intégration continue et la livraison continue (CI/CD) dans Microsoft Fabric

*46 min*
- Module *(8 Unités)*
Débutant
Analyste de données
Ingénieur Data
Microsoft Fabric
Microsoft Fabric met en œuvre CI/CD en utilisant les pipelines d'intégration et de déploiement Git. Ces outils vous aident à collaborer avec votre équipe de développement et vous fournissent un processus efficace de livraison et de mise à jour du contenu.

## Objectifs d’apprentissage

Dans ce module, vous allez apprendre à :

- Définir CI/CD et décrire comment il est mis en œuvre dans Fabric
- Implémentez le contrôle de version et l’intégration Git
- Utiliser les pipelines de déploiement pour automatiser le processus de déploiement
- Automatiser CI/CD à l'aide des API Fabric
## Prérequis

Avant de commencer ce module, vous devez vous familiariser avec l’interface de Microsoft Fabric et les concepts de base.
