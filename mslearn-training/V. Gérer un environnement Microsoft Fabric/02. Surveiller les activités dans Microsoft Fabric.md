# Surveiller les activités dans Microsoft Fabric

*50 min*
- Module *(7 Unités)*
Débutant
Ingénieur Data
Analyste de données
Microsoft Fabric
La surveillance vous permet d’obtenir une visibilité sur l’intégrité de vos systèmes de données. Le hub de supervision dans Microsoft Fabric collecte et agrège les données des activités Fabric. Microsoft Fabric Activator vous aide à effectuer des actions lorsque des modèles ou des conditions sont détectés dans les données de diffusion en continu.

## Objectifs d’apprentissage

Dans ce module, vous allez découvrir comment :

- Appliquer des concepts de supervision à Microsoft Fabric
- Utiliser le hub de surveillance dans Microsoft Fabric
- Déclencher des actions à l’aide de l’activateur dans Microsoft Fabric
## Prérequis

Avant de commencer ce module, vous devez vous familiariser avec l’interface de Microsoft Fabric et les concepts de base.
