# Administrer un environnement Microsoft Fabric

*41 min*
- Module *(7 Unités)*
Intermédiaire

Administrateur de base de données
Microsoft Fabric
Microsoft Fabric est une solution SaaS pour l’analytique données de bout en bout. En tant qu’administrateur, vous pouvez configurer les fonctionnalités et gérer l’accès en fonction des besoins de votre organisation.

## Objectifs d’apprentissage

Dans ce module, vous allez apprendre à :

- Décrire les tâches d’administration Fabric
- Naviguer dans le centre d’administration
- Gérer l’accès des utilisateurs
- Gouverner des données dans Fabric
## Prérequis

Compréhension de la plateforme Microsoft Fabric et de ses fonctionnalités et tâches d’administration.
