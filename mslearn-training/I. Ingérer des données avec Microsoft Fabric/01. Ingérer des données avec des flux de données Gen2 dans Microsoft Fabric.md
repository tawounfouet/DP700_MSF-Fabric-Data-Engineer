# Ingérer des données avec des flux de données Gen2 dans Microsoft Fabric

*1 heure(s)*
- Module *(7 Unités)*
L’ingestion de données est cruciale dans l’analytique. Data Factory de Microsoft Fabric offre des flux de données pour créer visuellement une ingestion des données et leur transformation en plusieurs étapes avec Power Query Online.
