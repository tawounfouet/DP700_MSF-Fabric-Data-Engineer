# Utiliser Apache Spark dans Microsoft Fabric

*1 h 20 min restant*
- Module *(0 sur 9 unités terminées)*
Apache Spark est une technologie de base pour l’analytique des données à grande échelle. Microsoft Fabric fournit une prise en charge pour les clusters Spark, ce qui vous permet d’analyser et de traiter des données dans un stockage de données à grande échelle.

## Présentation

*1 min*
- Se préparer à l’utilisation d’Apache Spark *(3 min)*
- Exécuter du code Spark *(3 min)*
- Utiliser des données dans un dataframe Spark *(5 min)*
- Utiliser des données à l’aide de Spark SQL *(7 min)*
- Visualiser des données dans un notebook Spark. *(5 min)*
- Exercice - Analyser des données avec Apache Spark *(45 min)*
