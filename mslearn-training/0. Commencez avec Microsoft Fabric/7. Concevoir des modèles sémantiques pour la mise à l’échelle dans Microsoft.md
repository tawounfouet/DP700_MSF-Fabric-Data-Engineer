# Concevoir des modèles sémantiques pour la mise à l’échelle dans Microsoft Fabric

*1 h 5 min restant*
- Module *(0 sur 8 unités terminées)*
Concevoir des modèles sémantiques pour la mise à l’échelle dans Microsoft Fabric. Choisissez le mode de stockage approprié, concevez des relations de schéma en étoile pour la clarté et les performances, créez des modèles de calcul évolutifs et configurez les paramètres qui prennent en charge les jeux de données volumineux et la consommation concurrente.
