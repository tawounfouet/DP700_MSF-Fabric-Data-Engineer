# Prise en main de SQL Database dans Microsoft Fabric

*1 h 10 min restant*

Vous allez découvrir comment utiliser les fonctionnalités des bases de données SQL dans l’environnement Microsoft Fabric, qui fournit une plateforme unifiée pour la gestion et l’analyse des données.
