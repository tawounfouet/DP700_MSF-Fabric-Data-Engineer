# Comprendre les principes fondamentaux de Microsoft Fabric IQ

*37 min restant*
- Module *(0 sur 6 unités terminées)*
Microsoft Fabric IQ permet de définir le vocabulaire métier dans une ontologie et de lier l’ontologie aux sources de données. Découvrez les éléments d’ontologie, les agents de données, Graph dans Microsoft Fabric et les modèles sémantiques Power BI. Découvrez comment la modélisation de l’ontologie diffère de la modélisation analytique traditionnelle en commençant par des concepts métier plutôt que des cas d’usage spécifiques.
