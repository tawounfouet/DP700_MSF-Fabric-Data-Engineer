# Grille de restitution

Chaque groupe presente son architecture et sa realisation en 2 minutes.

| Critere | 0 point | 1 point | 2 points |
| --- | --- | --- | --- |
| Architecture Fabric | Objets manquants | Objets principaux presents | Architecture coherente et justifiee |
| Bronze | Pas de brut conserve | JSON conserve | HTML + JSONL + audit |
| Silver | Peu de nettoyage | Nettoyage partiel | Typage, normalisation, deduplication |
| Gold | Tables non metier | Une table exploitable | Tables metier + agregats/schema etoile |
| Qualite | Aucun controle | Quelques controles | Controles traces et actionnables |
| Orchestration | Execution manuelle seulement | Pipeline incomplet | Pipeline bout-en-bout clair |
| Exposition | Pas de SQL/BI | Requetes simples | SQL + modele semantique ou mesures |
| Prise de recul | Description seulement | Justification partielle | Limites et ameliorations identifiees |

Score conseille :

- 0-7 : comprehension a consolider.
- 8-11 : objectif atteint.
- 12-16 : tres bonne maitrise pour une journee d'introduction.
